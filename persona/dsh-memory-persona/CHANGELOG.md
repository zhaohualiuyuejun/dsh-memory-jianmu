# CHANGELOG

## 0.3.8 — 2026-11-15

未接管注入时的「注入预览」不再红屏报错（发布前发现的产品级体验问题）：
- 以前：`injectEnabled=false` 且本机没有 soul-md 时，`/preview` 返回 `SOULMD_UNAVAILABLE`，界面显示红色「读取失败」，看起来像坏了。
- 现在：返回 `mode: "off"` 的**正常状态**，页面写清「现在没有任何人格/记忆被注入——不是故障，是开关没打开」，并给一个**「打开接管注入」按钮**（调 `/settings` 当场打开，无需重启）。
- `status` 的警告文案同步补上「且镜台未接管 —— 现在没有任何人格/记忆注入，去『注入设置』打开接管即可」。
- 设置页 `note` 文案澄清：未接管时若没有可用的回退源，就是完全没有注入。

> 注：本包默认 `injectEnabled` 仍为 **false**（公开版口径：新用户默认不接管注入）。本机（开发树）由 profile 覆盖或 `registry.settings` 打开。
