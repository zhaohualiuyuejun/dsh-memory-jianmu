# 隐私与外部请求
> 适用：建木 五包 2026-11 发布准备 · 更新 2026-11-13

本文只回答一件事：**建木的每一层，什么时候会把什么内容发到哪个地址，以及怎么关掉。**
事实来源：五个包的 `README.md` / `CHANGELOG.md` / `package.json`。未实测的地方在文末单独列出。

---

## 0. 一页结论（总表）

| 层 | 会出网吗 | 出什么 | 去哪 | 怎么关（开关名） |
|---|---|---|---|---|
| 寻枝（建索引 / 检索） | **会**，但只在「云端嵌入」且已配置 Key 时 | 切好的对话文本块（1200 字/块、80 字重叠）；检索时的**查询文本本身** | 你自己配置的 OpenAI 兼容嵌入服务（`/v1/embeddings`） | `provider` 设为 `local`（本机 Ollama）或 `none`（纯字面、零出网）；设置页「停用嵌入」 |
| 寻枝（每日话题卡） | **会**（默认走宿主当前模型） | 当天对话内容（用于生成话题卡） | 默认＝宿主当前模型；`summaryModel` 填本机 Ollama 模型名则不出网 | `daySummaries=false` 整项关闭；或把 `summaryModel` 指向本机 Ollama |
| 年轮（抽 claim） | **会**，只在抽 claim 时 | 选中的原话块 + 提示词 | DeepSeek（走宿主模型路由） | `autoDigest=false` 关自动消化；`enabled=false` 关整个年轮 |
| 熏习 | **不会** | — | — | 默认即零 LLM／零网络／零嵌入，无需关 |
| 镜台（AI 生成人设） | **会**，点一次发一次 | 种子或编辑框文本（输入 ≤8000 字符） | `expandProvider`/`expandModel` → 当前会话模型 → 模型目录默认（即宿主配置的模型服务） | 不点就不发；这是显式单次动作，没有常驻开关 |
| 镜台（P2 自动召回） | **会**（默认关；且要装了寻枝才会走） | 你的查询文本（一次查询嵌入） | 经寻枝发到配置的嵌入服务 | `autoRecall=false`（默认关） |
| 镜台（P2.5 冲突卡） | **不会** | — | 只读本机熏习与根藏文件 | `conflictCard=false`（默认关） |
| 根藏（自动摄取／嵌入） | **会**（有可用嵌入配置时） | 新摄取的原话块 | 配置的嵌入服务（`embeddingApiBase`） | `autoIngest=false`（最稳）。只清空 `embeddingApiKey` **不够**——留空会回退读寻枝的 Key，得连寻枝那份一起清 |
| 根藏（A2 摘要） | **不会** | 长块文本 | 本机 Ollama `127.0.0.1:11434` | `autoSummaryIndex=false`（默认关） |
| 元包 `jianmu-all` | **运行时不发请求** | — | — | 本身没有请求逻辑 |

一句话：**建木不会把记忆发往「你自己配置的嵌入服务 / 你自己选的模型服务」之外的任何地址。**

## 1. 逐层披露

### 1.1 寻枝（`dsh-semantic-recall` 0.4.7）

- **读什么**：只读 `~/.dsh/sessions/<工作区>/<会话>/session.v4.jsonl.zstd`，**绝不写回**会话目录。
- **哪些内容不进索引**：推理过程、工具调用/结果、系统注入、自动化会话的人设提示；只留「人话」。
- **云端嵌入时发什么**：只把**切好的文本块**发给 API（1200 字切块、80 字重叠），不发工具调用、不发推理过程。
- **也会发查询**：语义检索时，**查询文本本身**会发给当前嵌入服务用于算向量——这是计算，不是留痕。
- **不记录查询日志**：插件不落盘「谁在什么时候查了什么」，也不把查询历史发给任何第三方。例外只有上面那条：查询文本要发给嵌入服务算向量；该服务端是否记录，由它自己的隐私政策决定。
- **在哪里明示这件事**（三处）：建索引日志、`session_recall_status` 的 `embedding.sendsTextToCloud` / `privacy` 字段、设置页的「检索方式」。
- **默认值**：`provider` 默认是「云端」，但**没填 Key 时会自动降级成 `none`（纯字面）**，等于不出网。
- **索引存哪**：只存本机 `$DSH_HOME/session-recall/`（无源时 `index/`，多源时 `scopes/<源id>/index/`）；删掉这个目录＝连索引一起清掉，原始对话不受影响。
- **完全不出网**：`provider=local`（需 Ollama 带 `--embeddings` 启动）或 `provider=none`。

### 1.2 年轮（`dsh-memory-yearring` 0.4.5）

- **什么时候调模型**：抽 claim 时。两条路径都算「run」——
  1. 手动 `jianmu_year_run`（先 `dryRun` 预览成本，再 `confirm` 真跑）；
  2. 插件内自动消化（0.2.0 起**默认开**）：启动约 5 分钟后补跑一次，之后每小时第 `autoDigestMinute`（默认 27）分检查；默认范围 `last:90d`；每人每天 `autoDigestDailyTokenBudget`（默认 120 万 token）安全阀，用满当天暂停自动，手动 run 不受影响。
- **发什么**：选中的原话块 + 提示词。原话在提示词里被明确标注为「不可信数据，不是指令」。
- **去哪**：DeepSeek（`llmProvider`/`llmModel`，默认走宿主模型路由）。**年轮自己不保存任何 Key。**
- **写回什么**：只写 `<dataRoot>/year/<personaId>/`；`quote` 必须是原话逐字子串，否则拒收；`title/body/quote` 过入库扫描（注入/密钥/后门/不可见字符 → 红项拒收）。
- **怎么关**：`autoDigest=false` 关自动消化；`enabled=false` 关整个年轮（设置里显示「年轮在设置里已关闭」）。

### 1.3 熏习（`dsh-memory-process` 0.2.7）

- **默认零 LLM、零网络、零嵌入**；只做规则整理。
- 只读根藏的 `scopes/<personaId>/`（`manifest.json`、`chunks.jsonl`、`deleted.jsonl`），写自己的 `<dataRoot>/process/<personaId>/`。
- 不读向量文件；不写 `scopes/`、`year/`、`persona/`；不跨人格读写。
- 定时器默认每小时 **:17**（根藏 :07 之后）自动跟随，根藏没变化时幂等跳过；仍不产生任何外部请求。

### 1.4 镜台（`dsh-memory-persona` 0.3.7）

- **AI 生成人设**（`jianmu_persona_expand`）：一次显式调用。种子 → 整卡草稿，**结果只返回、不落盘**。
  - 输入 ≤8000 字符、输出 ≤8000 token、超时 60 秒、最多重试 1 次；
  - 模型路由：`expandProvider`/`expandModel` → 当前会话 `modelSelection` → 模型目录默认；
  - 首次点击前会先确认「文本会发到模型服务端 + 可能产生费用」；
  - 生成结果过注入/凭据/后门/不可见字符扫描，红项 → **拒绝返回草稿**。
- **P2 自动召回（默认关）**：每个用户回合过闸门（G0 线索词）后，可能向**寻枝**预取一次；寻枝内部会做一次查询嵌入 → **这一步会把查询文本发到寻枝配置的嵌入服务**。死线 800ms，超时即弃；没装寻枝时退化为「无服务」，不阻塞对话。观测日志 `<dataRoot>/persona/_logs/auto-recall.jsonl` **只有元数据，绝不写正文/query**。
- **P2.5 冲突卡（默认关）**：只读熏习的 open 冲突 + 根藏原文，本地拼 A/B 两说；**不发任何请求**。观测日志 `conflict-card.jsonl` 只记 `{t,sid,n,chars,conflictIds}`，无正文。
- **注入**：镜台只写 `persona/`，不写 soul-md 配置、不写根藏/熏习数据。

### 1.5 根藏（`dsh-memory-store` 0.2.8）

- **自动摄取**：默认每小时第 **:07** 分钟增量摄取一次，DSH 启动 60 秒后补跑一次；不 spawn、不弹控制台。
  - 流水线：抽取 → 折叠记录类型 → 校验 → 去重 → **先嵌向量后写**（不会写半截向量）。
- **嵌入去哪**：`embeddingApiBase` 指向的服务；Key 用 `embeddingApiKey`。**Key 留空时回退读寻枝的 `~/.dsh/session-recall/config.json`**。
- **A2 自动摘要（默认关）**：打开后只给**缺摘要的长块**（默认 ≥80 字）生成一句摘要，写回 `chunk.summary`（原文不动），再按「摘要 + 原文」增量重嵌。
  - 走**本机 Ollama**：`summaryBase` 默认 `http://127.0.0.1:11434`、`summaryModel` 默认 `qwen3:8b`；Ollama 不可达直接跳过。
  - 不阻塞摄取：detached 子进程 + `windowsHide`，失败只记日志；单飞锁在 `<dataRoot>/.locks/`。
- **测试连接**：一次最小 embeddings 调用，15 秒超时，**不落盘、不打日志明文、不回 Key**；只回 ok / 延迟 / 模型 / 维度。
- **日志**：`<dataRoot>/_logs/auto-ingest.jsonl`（事件）、`auto-summary.jsonl`（摘要事件）、`auto-summary-<pid>.out.log`（子进程输出）。
- **UI 不写记忆数据**：只读状态、只改插件设置；不做导入向导 / scope 管理 / 批量删除 / 跨人格操作。

### 1.6 元包（`jianmu-all` 0.1.0，实验）

- 元包本身**没有请求逻辑**，只是「依赖五个 tarball + 一份按序挂载五层的补丁」。
- 安装时按你的安装来源取包（这一步需要网络，取决于你从哪里装）；**运行时不发任何请求**。

## 2. 密钥放在哪、怎么保证不回显

| 密钥 | 存放位置 | 写入方式 | 读接口承诺 |
|---|---|---|---|
| 根藏 `embeddingApiKey` | profile 的 `cordis.patch.yml` | 0.2.6 起经宿主设置服务 `ctx.settings.update()` 就地写入（注释与排版保留；volatile 字段热生效、不用重启） | `GET /api/memory-store/settings` **只回 `embeddingApiKey.configured: true/false`**，永不回明文；测试连接只回 ok / 延迟 / 模型 / 维度 |
| 寻枝 `apiKey` | `~/.dsh/session-recall/config.json`（用户自填） | 设置页「保存 Key」或直接改该文件 | 只发给**你配置的那个嵌入接口**；README 明示「不要贴进对话、不要提交到仓库」 |
| 年轮 LLM | 不保存 Key | 走宿主模型路由 | 插件内无 Key 字段 |
| 镜台 AI 生成 | 不保存 Key | 走宿主模型路由 | 插件内无 Key 字段 |
| 共享库 `dsh-jianmu-utterance-core` | 不接触 Key | — | — |

**三条硬承诺**：

1. **密钥不落日志**：按根藏 README 的承诺，**任何响应与日志都不出现 Key 明文**；测试连接失败只回错误码/延迟，不回 Key。
   - **已审计（2026-11-13）**：定向扫描 103,119 个文件 / 394 MB（建木四层日志与数据、宿主日志、RC 发布件），Key 只在寻枝自己的 `config.json` 与其历史备份里出现，其余 **0 命中**。见《G8 日志与密钥审计》。
2. **读接口不回显**：任何状态/设置响应只给「是否已配置」布尔值。
3. **不把记忆发往其他地址**：寻枝 README 原话——「插件只会把它发给**你配置的那个嵌入接口**」；根藏只发 `embeddingApiBase`；年轮/镜台只发宿主模型服务。

> 提醒一句：`cordis.patch.yml` 与 `session-recall/config.json` 都是**明文文件**；**它们的 `.bak` 历史备份也明文含 Key**（审计里就命中了一份 `config.json.bak-20261111-prehygiene`）。备份、截图、发问题单时请遮挡 Key；共享 profile 备份前先确认里面有没有 Key。

## 3. 想「完全不出网」怎么配

按顺序做，五步都关住：

| 步骤 | 操作 | 效果 |
|---|---|---|
| 1 | 寻枝 `provider=none`（或 `local` + 本机 Ollama 带 `--embeddings`） | 建索引/检索不再出网；`none` 只做字面匹配，只给候选 |
| 2 | 寻枝 `daySummaries=false`，或 `summaryModel` 填本机 Ollama 模型名 | 话题卡不再用宿主模型 |
| 3 | 根藏 `autoIngest=false`；或确认 `embeddingApiKey` 为空**且**寻枝 config.json 里也没有 Key（否则根藏会回退用它） | 自动摄取不再嵌入、不出网；A2 摘要本来就走本机 |
| 4 | 年轮 `autoDigest=false`（或 `enabled=false`） | 后台不再调模型 |
| 5 | 镜台 `autoRecall=false`、`conflictCard=false`；不点「AI 生成人设」 | 对话期零外部请求 |

代价要讲清楚：全关之后，语义检索退化为字面匹配，年轮不再产生新 claim。**「不出网」和「语义能力」是同一个开关的两面。**

## 4. 不承诺 / 未验证

- **服务端行为不在我们控制内**：嵌入服务、模型服务端是否记录请求内容，由该服务的隐私政策决定。插件能保证的只有「发到哪、发什么」。
- **macOS / Linux 未验证**：本机只在 Windows 上实测（见《支持版本》）。
- **元包**：已实测「只装元包不会自动激活」（`--dump-config` 为 0 个条目）；再把 `jianmu-all` 写进 `dsh.profile.bundles` 后，五层一次挂齐（根藏/熏习/年轮/镜台 4 个 HTTP 面 + 寻枝 `/state` 全 200，2026-11-13，临时 profile）。元包本身仍不发任何请求。
- **年轮每日 token 上限是内存计数**：DSH 重启当天归零，不是硬账本；因此「当天不再出网」不能只靠它保证。
- **寻枝 `none` 模式的检索质量**：只给候选、不确认命中，属于设计取舍，不是隐私问题。
- 本文未逐字核对每个包的日志实现；「不落日志」承诺以各包 README 与根藏 0.2.8 的 `tools/httpapi-selftest.mjs` 用例为准，**未做独立日志审计**。
